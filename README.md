# Healthcare Data Analysis and Machine Learning

## Project Overview
This project performs healthcare data analysis and machine learning using the Diabetes Health Indicators dataset.

## Objectives
- Explore and clean the dataset.
- Analyze diabetes categories and health indicators.
- Create graphs and visualizations.
- Train a Decision Tree classification model.
- Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
- Identify important features used by the model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning
A Decision Tree Classifier is trained to classify the dataset into three categories: no diabetes, prediabetes, and diabetes.

## Project Files
- `healthcare_final_data_science_project.ipynb` — Data analysis, visualizations, and machine learning.
- `model_predictions.csv` — Actual and predicted results.
- `model_evaluation_report.csv` — Model evaluation metrics.

## Disclaimer
This project is for educational purposes only. The model is not intended for medical diagnosis or healthcare decisions.
